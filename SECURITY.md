# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Use
[GitHub private vulnerability reporting](https://github.com/ssfuisu/ZT-Manager/security/advisories/new)
instead and include a description, the affected version and steps to reproduce.

You can expect a first answer within a few days. Once a fix is released, the report is
credited in the changelog unless you prefer to stay anonymous.

## Scope

Relevant areas include, for example:

- extraction of crafted archives writing outside the target folder,
- the Wi-Fi share web server (path traversal, authentication bypass),
- file encryption and the app lock,
- handling of files opened from other apps.
